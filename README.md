# 🔥 Campaign Roaster AI

> Paste any brand campaign. Get brutal marketing feedback + a rewrite.

An AI-powered marketing analysis tool built with Google Gemini and Streamlit. Analyses any brand campaign using AIDA, STP and other marketing frameworks — then rewrites it better.

**Built by Vanshika Nagvani | [github.com/vanshika-nagvani](https://github.com/vanshika-nagvani)**

---

## What it does

- Scores your campaign out of 10
- Breaks it down using AIDA framework
- Identifies what's working and what's weak
- Gives a sharp, witty roast of the campaign
- Rewrites the campaign with stronger copy
- Suggests one bold new creative direction

## Demo campaigns to try

- Blinkit Diwali: "Gifts delivered in 10 minutes. Because love shouldn't wait."
- Zepto: "Faster than a makhan chor."
- Any brand campaign you want analysed

## Built with

- Google Gemini API
- Streamlit
- Python

## How to run locally

1. Clone this repo
2. Install dependencies: `pip install streamlit google-generativeai`
3. Run: `streamlit run app.py`
4. Enter your Gemini API key in the app
